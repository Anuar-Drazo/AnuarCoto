# Cálculo Mental

Cálculo Mental es una aplicación de escritorio para practicar operaciones matemáticas. Incluye suma, resta, multiplicación y división, además de un modo Competencia y una sección de Ranking.

## Cómo ejecutar el programa

1. Instala [Python](https://www.python.org/downloads/).
2. Abre una terminal en la carpeta del proyecto e instala las dependencias:

   ```bash
   pip install -r requirements.txt
   ```

3. Ejecuta la aplicación:

   ```bash
   python main.py
   ```

La primera vez se creará automáticamente el archivo `anuarcoto.db`, donde se guardan las cuentas y los resultados.
