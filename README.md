   # Mindrazo

Mindrazo es una plataforma de Calculo Mental inspirada en Alberto Coto, es una aplicación de escritorio para practicar operaciones matemáticas de manera mental para niños de primaria. Fue creada con el proposito de pasar una materia y de ayudar a los niños a desarrollar su cerebro mediante divertidos juegos de ejercicios mentales que estimulan su concentracion. Incluye suma, resta, multiplicación y divisiónd ademas de un modo Competencia donde podras medir tus habilidades con un limite de tiempo e intentos y una sección de Ranking donde podras ver tus resultados y competir con otros para ser el top 1.

## Cómo ejecutar el programa

1. Instala [Python](https://www.python.org/downloads/).
2. Abre una terminal en la carpeta del proyecto e instala las dependencias:

   ```bash
   pip install -r requirements.txt
   ```

3. Ejecuta la aplicación:

   ```bash
   python main.py
   ```

La primera vez se creará automáticamente el archivo `anuarcoto.db`, donde se guardan las cuentas y los resultados.
